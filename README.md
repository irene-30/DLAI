# Interpretable Math Reasoning: Standard VQ-VAE vs. Riemannian Latent Space Oddity

This project implements an advanced mathematical reasoning pipeline for Large Language Models (LLMs), comparing the effectiveness of different latent space representations in supporting complex cognitive processes. The work is inspired by the combination of textual **Chain-of-Thought (CoT)** techniques and discrete latent abstractions.

The system compares two paradigms:
1.  **Standard Baseline**: Based on a classic **VQ-VAE** with a Euclidean metric.
2.  **Riemannian Oddity**: Based on the "Latent Space Oddity" framework, utilizing a curved Riemannian manifold to map reasoning in a geometrically coherent way.

## Chain-of-Thought (CoT) and Latent Abstraction

### What is Chain-of-Thought?
**Chain-of-Thought (CoT)** is a technique that enables language models to decompose complex problems into intermediate reasoning steps before arriving at a final solution. While highly effective, standard textual CoT has limitations:
* **Length**: Generating entire paragraphs of intermediate steps is computationally expensive.
* **Redundancy**: Many words support textual coherence rather than core logical information.

### The "Token Assorted" Approach
Following the research in *"Token Assorted: Mixing Latent and Text Tokens for Improved Language Model Reasoning"*, this project proposes a **hybrid representation**. Instead of using only text, the model is trained to utilize **discrete latent tokens** generated by a VAE to abstract initial or intermediate reasoning steps. 
This method allows for:
* Significantly reducing the length of reasoning traces.
* Maintaining or improving performance on logical-mathematical benchmarks like **GSM8K** through an extended vocabulary that includes latent tokens.

## Geometry and "Latent Space Oddity"

While the standard approach treats latent tokens in a "flat" Euclidean space, this project implements the architecture proposed in *"Latent Space Oddity"* to improve the quality of these abstractions.

Since the decoder is non-linear, the latent space is inherently distorted. We characterize this distortion using a **stochastic Riemannian metric**:
$$M_z = (J_z^{(\mu)})^T (J_z^{(\mu)}) + (J_z^{(\sigma)})^T (J_z^{(\sigma)})$$

By integrating a **Radial Basis Function (RBF) network** to model precision (inverse variance), we force reasoning tokens to settle only on manifold regions where the model is certain. This avoids "shortcuts" in untrained areas of the latent space that would lead to logical errors.

## Requirements and Setup

### Hugging Face Permissions
The project requires access to gated models and datasets. You must:
1.  **Request access to Llama-3.2-3B-Instruct** on the official Meta Hugging Face page.
2.  **Accept the terms for MetaMathQA** if required by the dataset repository.
3.  **Configure an HF_TOKEN** in your environment (Colab Secrets) to authenticate.

### Hardware and Optimizations
Optimized for **NVIDIA T4 GPUs (16GB VRAM)** using:
* **PEFT/LoRA**: Fine-tuning adapters while keeping the LLM backbone frozen.
* **8-bit Paged AdamW**: Reducing the memory load of optimizer states.
* **Gradient Checkpointing**: Critical VRAM saving during training.
